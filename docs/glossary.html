Appendix K. Glossary (Oct 24 2026)

This appendix defines the main technical terms of the paper, in alphabetical order. Each entry gives the definition as the paper uses it, the notation, where it is defined ("Defined in"), and the source in the reference list. A Usage note marks places where the paper's usage differs from the literature, or where one word has several meanings in the paper. "See also" points to other entries. References 47–55 were added for this glossary only (reference 56 was added with H.37): they credit standard notions the paper uses but did not cite. The glossary adds no results. Where it and the body text differ, the body text is authoritative.

  • Absorbed class, absorbed vertex (r; Wo = U_oU_r†). Fix an output r and absorb Ur† into the source state, so that the board becomes Wo = U_oU_r†. The class of r is the absorbed class, and r the absorbed vertex. Vertices o and q are in the same group when W_oW_q† is monomial. Each group has a representative ρ and an F₂-subspace H_ρ, spanned by the X-parts of the Pauli support of W_ρ. Defined in H.17.11(a); used in Lemma D (H.17.17). Paper's own construction. See also SH, SH⁺, SH⁺⁺, SH_grp, SH_grp^r; Monomial.
  • Arc consistency. A pruning step for finite constraint problems. A value in one variable's domain is deleted when some other variable has no value compatible with it. It never deletes part of a complete solution, so a search that combines it with full branching is still exhaustive. The four-class search uses it on the Pauli-rule tables (one 64 × 64 Boolean table per vertex pair). Used in H.17.13–H.17.17; explained in H.26.1a. Source: constraint satisfaction (Mackworth 1977).
  • Activation-controlled (measurable process function). A process function whose output space splits into countably many product regions. In each region at most one party is active, its own output is unconstrained, and its translation amount is an arbitrary measurable function of the other outputs, while the inactive amounts are constant. Two further conditions apply: Lugano-type exclusivity, and the skeleton with zero amounts is a process function. Example: the Lugano pattern on parities with continuous or even nowhere-continuous amounts. The closed loop with arbitrary local unitaries is unitary (F.5.12, Round 18). Paper's own term. See also Countably controlled; Uniformly approximable.
  • Admissible board. A board {Uo} in which every Uo is unitary and every pair o ≠ o′ obeys the Pauli rule. This is equivalent to purity of the Switchboard built from it (H.7.1, H.8.1). Pairwise admissible (H.17.3, H.17.9) means that the Pauli rule holds for one given pair. Defined in the H.17 preamble. Paper's own term. See also Board; Hard board; Pauli rule.
  • AFNB. Araújo, Feix, Navascués and Brukner [17], the source of the paper's notions of pure process and purification. See Pure process; Purification.
  • Ancilla. An auxiliary system on which a party's local operation may also act. Local ancillas are Xk, Yk in Appendix A. A shared, possibly entangled ancilla is treated in Appendix A Step 3 and H.8.2 ("ancillas add nothing" for Switchboards). The Lean counterexample is checked for finite ancilla types, for ancilla index sets of any cardinality (unitary kernels), for ancillas in arbitrary Hilbert spaces (isPureHilbert_Vsb L-099), and for normal CPTP local channels with ancillas of any cardinality (valid_normalCPTP_Vsb L-101, countable; valid_normalCPTP_Vsb_any L-152, Round 13) (H.12.3, H.19, H.20). With infinite-dimensional ancillas, "pure" means that the closed loop is a unitary of CP ⊗ ⨂Kk for all Hilbert spaces Kk and unitaries on C² ⊗ Kk (H.19.3). For finite V this is equivalent to purity against finite ancillas (H.19.4; Lean: isPure_iff_isPureHilbert L-193, H.20.1). In the process-matrix framework, ancillas of any cardinality are allowed by IsValidPMInf and IsPurePMInf, which agree with the finite-ancilla notions (isValidPMInf_iff L-141, isPurePMInf_iff L-139, H.20.4). Standard [14, 17].
  • Antinomic → Nomic, antinomic.
  • Audit (completeness audit). A separate check that an exhaustive search covered everything it claims to cover. It recounts the cases (here, recomputing the orbit key of all 21,906 labelled geometries) and matches them against the search's checkpoint records. For glue_k4 it found all 2,722 canonical geometries done, with 0 candidates and 0 UNRESOLVED (glue_k4_audit.py). Defined in H.26.1; explained in H.26.1a(d). Paper's own usage.
  • Baumeler–Wolf polytope → Valid (polytope).
  • Board (Uo, also written Co; "the board"). In a Switchboard, Uo := Co is the 8×8 unitary that the joint output o applies to the source (H.8 notation). In H.12, "eight 8×8 boards" means the eight Uo. Elsewhere "a board" means the whole family {Uo}_{o∈{0,1}³}, as in "X-type board" and "≤3-term board". Defined in H.8, H.17 preamble. Usage note: the paper's own term, not used in the literature. See also Switchboard; Admissible board; Term.
  • Canonical representative; orbit key. For a finite set acted on by a symmetry group, the orbit key of an element is the lexicographically smallest of its images, so two elements are in one orbit exactly when their keys are equal. The canonical representative of an orbit is one fixed member: in glue_k4canon.py, the first geometry in enumeration order with that key. A search over canonical representatives is complete when every orbit member has the same answer, which holds for symmetries of the problem (H.17.15(d)). Defined in H.17.17; explained in H.26.1a(b). Standard technique.
  • Candidate, job, UNRESOLVED (search outcomes). In the exact searches of H.17.13–H.17.17, a job is one assignment of classes (or labels) and pair supports, handed to an exact finite-domain solver. A candidate is a complete assignment that passes every search filter. Each candidate is then checked against the full test (H.17.11a) and the hull facets. A job is UNRESOLVED if the solver's node budget runs out first. A run counts as "clean" when it has 0 candidates and 0 UNRESOLVED. Defined in H.17.15, H.17.17. Paper's own terms. A worked example is in H.26.1a(e).
  • Causal box. A quantum system that receives and emits messages at positions of a partially ordered set, closed under composition [42]. Mentioned in H.18.4 as a framework the paper does not use.
  • Causal correlations; dynamic-order causal polytope. Correlations P(i|o) between the parties' outputs o and inputs i that can arise with a possibly dynamical causal order: a party acts first, and its output can decide the order of the rest. For three binary parties they form a polytope with 138,304 deterministic vertices. Defined in H.15.7a. Sources: [14] for two parties; [52, 53] for the multipartite definition and polytopes. See also Causal inequality.
  • Causal inequality. A linear inequality satisfied by every causal correlation. Its violation certifies that no causal order explains the data. The paper's inequalities have integer coefficients and minimum 0 over the 138,304 deterministic causal strategies. They are certified by LP plus an exact rational Farkas vector. Defined in H.15.7b, H.15.7d. Source: [14]; for the polytope approach, [53].
  • Causally separable; classically causally separable. A quantum process is causally separable if it is a mixture of processes with a definite or recursively dynamical order [14, 52, 55]. The paper's classically causally separable is a classical process that is a convex combination of processes, each with some party first with valid conditionals. Defined in H.1. Usage note: this is the diagonal (classical) analogue of the recursive definition of Wechs, Abbott and Branciard [55, Def. 5] and of the extensible causal separability of [52]. It is not the quantum notion. See also First party.
  • Choi matrix; Choi vector (JA; |U⟩⟩). The Choi matrix of a linear map A on L(H) is JA = Σ_{ij} |i⟩⟨j| ⊗ A(|i⟩⟨j|). Choi's theorem says A is completely positive iff JA ≥ 0 [48]. For a unitary U, J is |U⟩⟩⟨⟨U| with |U⟩⟩ = Σi |i⟩ ⊗ U|i⟩. Defined in Appendix A (Lean: PFUL.Choi.isCP_iff_choi L-044); used in Lemma D.1 and Appendix F (countable alphabets). In the process-matrix framework of H.19.1, a local operation is CPTP iff its Choi matrix C ⪰ 0 and Σb C((a,b),(a',b)) = δ_{aa'} (PFUL.PM.IsCPTPChoi, isCPTPChoi_choiOf_iff L-186). The counterexample's Choi vector is choiVec Vsb, and its process matrix is choiMat Vsb = |Vsb⟩⟩⟨⟨Vsb| (H.19.2). For channels with infinite ancillas the Choi operator is not trace class, and the Kraus/kernel form is used (H.19.5). Round 13 allows Choi kernels on ancillas of any cardinality (IsCPTPKer: PSD finite sections, unconditional partial trace; H.20.4).
  • Clarabel.jl; BigFloat. Clarabel is an interior-point conic solver, with a Rust implementation (used through Python) and a Julia implementation, Clarabel.jl, that is generic in the number type. Run with Julia's BigFloat, Clarabel.jl solves SDPs in arbitrary precision. Installed user-locally for Round 27 (H.34.2). On the full 216-cone problem it did not converge within 30 minutes in Float64. The exact certificate of H.34 needed only a double-precision solve on the reduced face, done with the Rust Clarabel. CITED software (Goulart and Chen).
  • Class (κ; V_κ). Usage note: the word has several meanings in the paper, depending on the section.
    • (a) In H.17.9 and H.17.15(a), a class is a generator tuple: () for V = 1, (A) for a two-term class α + iβA, and (A, B) with A, B anticommuting for a three-term class α + i(βA + γB). There are 1,071 non-identity classes, 1,072 with the identity.
    • (b) From H.17.16 on, a class is a unitary up to a left Pauli: Uo = P_oV_κ(o). Two classes can then share a generator tuple, and in H.17.17 that tuple is called the class's label.
    • (c) In H.10.6, H.14.1 and H.17.8, the classes are the blocks of a partition κ of the outputs o.
    • (d) "Symmetry classes" of boards (H.10.4, H.13.3, H.14.2) are orbits of boards under the symmetry group, and "LP classes" in D.7 are classes of facets.
    • See also Label; Orbit; Tuned.
  • Class bound (Theorem H.17.17). An admissible ≤3-term board has at most four classes, in sense (b) of Class. With exactly four, each class is one cube edge along its unique rigid direction. Proved in H.17.17; also checked in Lean (https://github.com/drewarrowood/process-function-unitary-lift/blob/main/lean/PFUL/LemmaH.lean), under hypotheses stated there. See also Rigid qubit; Geometry.
  • Class-constant selection. Given a partition κ of the outputs, a selection that picks for each output o an input string from a set that depends only on the class κ(o). The coset-transport theorem needs every class-constant selection to be a PF. Defined in H.10.6, H.17.8(a). Paper's own term. See also Coset transport.
  • Class-lift relaxation (X; Z(i); R). For PF phase boards vo = Doψ on a Lugano-type rule, the 64×64 lifted matrix X[(o,z),(o′,z′)] = ψ_zψ̄_{z′}Π_k ukek, with ek = ok xk(z) − o′_k xk(z′), is PSD and depends on the phases only through the class (z, z′, e). So are the framed blocks Z(i). Keeping only these properties, the frame spans of Lemma H.30.1 and the normalisation gives a semidefinite relaxation (SDP2; R when the cone on X is dropped) whose minimum bounds any facet from below. Its rounded dual certifies orbits 54 and 66 (Theorem H.31.3). Defined in H.31.2. Paper's own construction (a symmetry-adapted moment relaxation). See also Moment relaxation; Facial reduction; Lugano-type family.
  • Classical process (p(i|o); also W diagonal). A conditional probability p(i|o) of the parties' inputs i given their outputs o, such that for every tuple of local deterministic interventions fk: Ik → Ok the total probability Σi p(i|f(i)) equals 1. Equivalently, a process matrix that is diagonal in the computational basis. Validity under all stochastic interventions follows because the condition is multi-affine (H.12.2). Defined in the Appendix H preamble, D setting, H.17.5. Usage note: this is Baumeler and Wolf's "logically consistent classical process" [15]. See also Valid (polytope); PF (process function).
  • Classical restriction; reading a process in a frame. Decohere the agent wires (and fix bases on P and F) of a pure process in a chosen local basis, the frame, and record the result as a classical process. The H.13.2 board read in the Hadamard frame gives a classical process outside conv(PF), and read in the computational frame it gives one inside. Defined in H.15.8, H.15.9(B). Paper's own phrasing. See also Frame.
  • Classical multiple-use model. A classical acyclic network in which each agent's classical instrument may be run more than once (once per possible input value, by separate sub-agents), and a central node decides afterwards which run counts. It reproduces every valid classical process (H.21.6(a)), so it says nothing about purity. Defined in H.21.6. See also Single-use realisation; Fine-grained causal model.
  • Classical-output pure process (COPP) (Uo). A pure process V|s⟩P|o⟩AO = (Uo|s⟩)_{AI}|o⟩F whose future records the agents' outputs, with one unitary Uo on the agents' input qubits for each output triple. It is valid iff Σo Uo†(⊗k M^kok)Uo = 1 for all binary POVMs. Equivalently, an alternating sum over every nonempty set of parties vanishes, and in particular no agent's output can reach its own input. PF phase boards and forward PF lifts are COPPs. Defined in H.29.1. Paper's own term. See also Phase-process component.
  • Classically controlled board. A qubit board ik = Uk, o_{−k} sk in which each party's unitary is selected by the other parties' classical outputs. It is valid for two-valued Lugano routing and, numerically, invalid for every other control pattern tested (H.24.2, Round 17). Paper's own term. See also XOR board.
  • Cone inclusion (weighted SOS). If a weight h is a product of Hermitian squares (here (2c_ks_k)² = sin²t_k and |1 − uk|²/4 = sin²(ak/2)), then h times an SOS is itself an SOS of higher degree, with a widened u-basis. So a weighted certificate Σj h_jS_j at degree D lies in the plain cone at the lifted degree, and weights only make that cone cheaper to reach. Defined in Remark H.37.1. Standard. See also Zero-set-structured certificate.
  • Corner form (leading corner form), corner torus. A corner torus is a set {t ∈ {0, π}³} of the reduced family, on which M is diagonal and independent of a (Lemma H.37.4a). The leading corner form L is the 2 × 2 matrix of leading terms of the Schur complement of Mh(εη) on the kernel at t = 0, after rescaling by diag(1, 1/ε). For orbit 28 it is PSD, with an explicit sum-of-squares formula for det L (Theorem H.37.4). Defined in H.37.4. Paper's own term. See also Projective coordinates; Transverse coefficient.
  • Coset transport (Pauli coset-transport theorem). Suppose a board can be written Uo = Xa(o)G_κ(o), where κ partitions the outputs and each G_κ is a unitary in the span of {X^h : h ∈ H_κ} for a subgroup H_κ (H.10.6); H.17.8(a) allows a monomial in place of Xa(o). If every class-constant selection is a PF, then p_φ ∈ conv(PF) for every source state. Proved in H.10.6, H.17.8(a); the right-absorbed version is H.17.11(a). Paper's own theorem. See also SH, SH⁺, SH⁺⁺, SH_grp, SH_grp^r.
  • Countably controlled (measurable process function). Like finitely controlled, but each output space may split into countably many cells, so w can take infinitely many values (example: Lugano on the parities of the integer parts, with unbounded odd translations, F.5.10). The closed loop M = Σc ⊗k Pck Vk Sω_k(c) is then a strongly convergent series and is unitary (F.5.10, Round 16). Paper's own term. See also Finitely controlled.
  • Cube, vertex, edge, direction (o ∈ {0,1}³; ep; D(o,o′)). For three binary parties, the joint outputs o are the vertices of a cube. An edge along direction ep joins o and o ⊕ ep, which differ in party p's output only. D(o,o′) := supp(o ⊕ o′) is the set of parties whose output changed. A string x covers D if x ∧ D = D. Defined in H.8 notation, H.17. Standard combinatorics; the terminology is the paper's own.
  • D-CTC, P-CTC. Deutsch's self-consistent model of closed timelike curves [10] and the postselected model [13], compared with process functions in Section 4 and H.15.1.
  • Deterministic intervention (fk: Ik → Ok). A local function from a party's input to its output. A process function gives exactly one consistent history for every tuple of them. Defined in Section 1. Source: [15, 16].
  • Deterministic-extrema polytope → PF hull.
  • Dual certificate; Farkas vector; inertia certificate. An exact witness that an optimum or an infeasibility is what is claimed. Examples:
    • rational multipliers y for the 72 validity equalities, showing that orbit 92 holds on all of Valid (H.17.5);
    • an integer Farkas vector certifying a causal inequality (H.15.7b);
    • rounded Hermitian Lagrange multipliers with an exact LDLᵀ check, bounding the NS and PPT relaxations (H.15.9(C′));
    • exact Hermitian inertia arguments showing that Eex1 and vertex orbits 7 and 50 are not purifiable (C.2).
    • Standard LP and SDP duality; the specific certificates are the paper's own.
  • Eex1 (= (C + C̄)/2). The three-party valid classical process of Baumeler and Wolf [15] that lies outside conv(PF). It is the uniform mixture of the circular identity channel C (x₁ = a₃, x₂ = a₁, x₃ = a₂) and its bitwise negation C̄, both logically inconsistent deterministic processes (Appendix C). The paper proves it is not purifiable (C.2). See also Vertex orbit.
  • EXACT-CERTIFIED → Result labels.
  • Exact-parametrisation search. A search over a family in coordinates in which every point is a valid process (here three phases and three Bloch directions, with the source eliminated as λ_min), so that no validity penalty is needed. It is trusted only after it re-finds the known crossings (orbits 26, 30, 31). Used in H.31.5. Paper's own term.
  • Exclusivity lemma; pairwise exclusivity. If w is a process function, then for every pair of outputs o ≠ o′ some party k whose output changed (k ∈ D(o,o′)) has the same input, wk(o) = wk(o′). Proved in Section 1 (Lemma). The converse, that pairwise exclusivity characterises PFs, is Dourdent et al. [23, Thm 7] (Section 1, "Converse"); for three binary parties it is checked exhaustively in H.10.3. The Pauli rule is its operator version (H.8.1).
  • Facet; facet inequality; facet operator; relative violation (g·p + g₀ ≥ 0; F = Σ g[i,o]Po,i + g₀).
  • Facial reduction (rounding a tight SDP certificate). When an SDP bound is tight, the dual PSD matrices are singular, and naive rounding destroys positivity. One first identifies their kernels exactly (here rational vectors read off the numerical kernel), restricts each dual matrix to the complement H = P G Pᵀ, then rounds G and solves the linear conditions exactly. G is positive definite, so small exact corrections keep it so. Used in H.31.3. In H.32 the starting kernels are the zero-set kernels, and further kernel directions come from the dual of the max-margin problem. That works for orbit 66 (margin 3.6·10⁻³) but stalls for 57 and 75. In H.34 the same step, applied to the torus-weight blocks of the Hermitian SOS on top of an exact zero family, completes it for 57 (margin 1.2·10⁻³). Standard (Borwein–Wolkowicz; Peyrl–Parrilo rounding).
    • A facet is a facet of the PF hull, written g·p + g₀ ≥ 0, modulo the 27 independent validity equalities. For three binary parties there are 29,344 facets in 93 orbits (D.7). Facets are numbered by their index in the computed list (e.g. facet 1741, the H.12 certificate, and facet 16962, the H.13.2 certificate) and orbits by 0–92 (e.g. orbit 82, the class-0 inequality of D.7).
    • The facet operator F = Σ_{o,i} g[i,o]Po,i + g₀ evaluates a facet on a Switchboard as an operator on the source (H.8, H.10.4).
    • The relative violation is the violation divided by the facet's range on PFs (H.13.3, Appendix J).
    • See also Orbit; Never-crossed orbit; Genuine orbit.
  • Families A, B, C; Ring, Chorus, Switchboard, Shadows. The three families of three-party binary purifications without an operator-first party found in H.7:
    • A: single-PF lifts of the 64 Lugano-orbit PFs (informal name: the Ring);
    • B: coherent blends of causal orders, the C.1 lift of a blend of three causally ordered PFs with different first parties (the Chorus);
    • C: the Switchboard.
    • A fourth informal name, the Shadows, refers to the numerical purifications lug_21–23. The names are listed in H.7 and used in graded.md, Section 58e. Paper's own names. See also Switchboard; Lugano process.
  • Fine-grained causal model. A causal model whose nodes are finer than the parties' laboratories (individual systems or sectors), used to ask whether a process can be embedded in an acyclic spacetime. Discussed in the H.15.7 setting. Sources: Vilasini and Renner [32, Thm 5]; Vilasini and Colbeck [33, 34]; sector-level structure, Ormrod, Vanrietvelde and Barrett [46]. See also Routed graph; QC-QC.
  • Fine-tuned. In Baumeler and Wolf [15], a classical process is fine-tuned if it lies outside the deterministic-extrema polytope, i.e. outside conv(PF). Quoted in this sense in H.15 (setting). Usage note: not the same as the paper's tuned (H.17.10), and also distinct from fine-tuning in causal-model discovery [33]. See also Tuned.
  • Finitely controlled (measurable process function). A process function w on continuous groups such that each output space splits into finitely many cells and every wk(o) depends only on which cells the outputs lie in, e.g. the Lugano function lifted to ℝ³ by threshold sets. For such w the closed loop with arbitrary local unitaries is a finite sum, M = Σc ⊗k Pck Vk Sω_k(c), and it is unitary (F.5.9). Defined in F.5.9. Paper's own term. See also Countably controlled (F.5.10).
  • First party; marginally first; first with valid conditionals; operator-level first. Three different strengths of "A acts first":
    • marginally first: the marginal p(a|x,y,z) = Σ_{b,c} p does not depend on the outputs (H.1);
    • first with valid conditionals: in addition, every conditional qa,x(b,c|y,z) is a valid bipartite classical process (H.1);
    • operator-level first in a purification V: V = (V′ ⊗ 1_{IA})(S ⊗ 1O), where S: P → IA ⊗ R, so A's input is produced before any output is read (H.6).
    • Operator-first implies first with valid conditionals (H.6). Marginally first does not (H.5). Paper's own definitions, modelled on [52, 55]. See also Last party; Causally separable.
  • Fixed-order process; relativistic causality. A process compatible with one fixed causal order of the parties, as tested in H.15.6 over the 6 orders. Relativistic causality in the sense of Vilasini and Renner [32] (H.15.1).
  • Forward PF lift; PF-wired box. A board V|s⟩P|a⟩AO = (⊗k Uk,wk(a))|s⟩AI|a⟩F built from a process function w, with arbitrary node unitaries, node-wire dimensions and source; the future F records the agents' outputs. Its statistics are those of a quantum box whose settings are wired by a refined PF, x = w′(o) (a PF-wired box). No PF-wired no-signalling box crosses the ten open orbits (Theorem H.27.1). Defined in H.27.1. Paper's own term. See also Refined process function; Time-reversed PF lift.
  • Frame (computational, Hadamard; Hd). A choice of local bases on the agent wires in which a pure process is read classically. Hd = H⊗3 is the three-qubit Hadamard. Defined in H.15.8, H.15.9(B). Usage note: "frame" is the paper's word, not the literature's reference frame or "causal perspective" [44]. See also Classical restriction; LU-equivalent.
  • G₄₈ (= (ℤ₂)³ ⋊ S₃). The symmetry group of the three-qubit Pauli-rule problem used to reduce class searches. An element g = (π, m) acts on a Pauli string (x | z) by z ↦ z ⊕ (x ∧ m) followed by the qubit permutation π. It maps admissible boards to admissible boards. The 1,071 non-identity classes fall into 61 orbits under G₄₈ (9 two-term, 52 three-term). Defined in H.17.15(b), (d). Paper's own construction.
  • G_φ path. The one-parameter family V_φ of pure X-type boards obtained by replacing √X in Theorem H.21.2 with G_φ = ½(1+eiφ)·1 + ½(1−eiφ)·X. It runs from a PF blend (φ = 0) through H.12 (φ = π/2) to φ = π (G_π = X), a frame-rotated time reverse of the Lugano process with the H.13.2 maximal violation 0.1404. Defined in H.21.7. See also Lugano family (VOKB).
  • Generalised Lugano board (LUA,UB,UC). |s⟩P|o⟩AO ↦ (UAlug_A(o) ⊗ UBlug_B(o) ⊗ UClug_C(o))|s⟩AI|o⟩F with arbitrary qubit unitaries in all three nodes, used with or without time reversal and with local frames on every agent wire. A fleshing-out of VOKB's Lugano graph, hence valid. When each Uk has eigenphase gap π it is locally equivalent to the Lugano purification. Defined in H.22.2. See also Lugano family (VOKB).
  • Generalized switchboard. V|o, s, t⟩ = Σe |e⟩I |o⟩F1 ⊗ (Co(s))e ⊗ |e ⊕ t⟩, where each Co: S → I ⊗ F′ is unitary and F′ is an extra sink. It is pure iff every 8×8 block of C_oC_{o′}† satisfies the Pauli rule. Defined in H.11.2. Paper's own term. See also Switchboard.
  • Generic; generic-support model. A ≤3-term board is generic if the Pauli support of every ratio U_oU_q† is the full product support of the two classes, with no cancellations. The generic-support model assumes this throughout. SH_grp holds for every admissible board in this model, by exhaustive exact enumeration. Defined in H.17.9. Paper's own term. See also Tuned.
  • Genuine orbit (of facets). One of the 22 never-crossed facet orbits that are not positivity. Orbit 92, the remaining never-crossed orbit, is positivity, and holds on all of Valid (exact dual certificate). Twelve of them were crossed in Round 15 (H.22.2): orbits 4–11, 14, 25 by a framed time-reversed Lugano board, and 53, 79 by a generalised Lugano board. Three more (26, 30, 31) were crossed in Round 21 by PF phase boards (H.28.1), so 7 remain open: 28, 54, 57, 66, 69, 75, 81 (unchanged after Rounds 22–24, H.29–H.31; Round 23 proves them on all non-Lugano families, Theorem H.30.2; Round 24 proves 54 and 66 on the Lugano-type families too, Theorem H.31.3). Defined in H.17.5, H.17.15(e); listed in J.1. Paper's own term. See also Never-crossed orbit.
  • Geometry (labelled, canonical). For the four-class search, a labelled geometry gives the class at each of the 8 cube vertices and each class's label, subject to the class bound and Lemmas A and B. There are 21,906 labelled geometries, and 2,722 canonical geometries up to cube translations × G₄₈. Defined in H.17.17. Paper's own term.
  • Grid-seeded multistart. A search in which a deterministic grid over the parameters is evaluated exhaustively, and the K lowest grid points in each cell of a coarse partition (here, each phase triple) are descended independently and then polished. L.3. Converse without ancillas [proved for finite equal local alphabets; numerically corroborated]

Setting: |Ik| = |Ok| = dk finite (otherwise no ancilla-free local unitaries exist and the question is vacuous), Ik = Ok = Zdk, M[s,e] = ∏_k Vk[sk, wk(s) + ek].

Theorem N.1. For w : ∏Ok → ∏Ik the following are equivalent: (i) w is a process function; (ii) M is unitary for every tuple of ancilla-free local unitaries; (iii) M is unitary for one Haar-random tuple (with probability 1); (iv) pairwise exclusivity: for all s ≠ s' there is k with sk ≠ s'k and wk(s) = wk(s').

Proof. Row Gram identity (summing over e factorises over parties): (M M†)[s,s'] = ∏_k Σ_{ek} Vk[sk, wk(s)+ek] conj Vk[s'k, wk(s')+ek] = ∏_k (Vk Tδ_k Vk†)[sk, s'k], δ_k = wk(s) − wk(s'), T the cyclic shift. Diagonal entries are always 1 (rows are always unit vectors), and M is square, so M unitary ⇔ all off-diagonal products vanish. (iv)⇒(ii): the factor with δ_k = 0, sk ≠ s'k is (V V†)[sk,s'k] = 0. (This is the Theorem of §1 with trivial ancillas.) (iii)⇒(iv): if (iv) fails for s ≠ s', every factor has either δ_k = 0, sk = s'k (factor 1) or δ_k ≠ 0. For δ ≠ 0, T^δ is not scalar, so V ↦ (V T^δ V†)[a,b] is a real-analytic function on the connected manifold U(d) that is not identically zero (diagonal: take v an eigenvector of T^δ; off-diagonal: take v not an eigenvector and u in the direction of the component of T^δ v orthogonal to v); its zero set is Haar-null. A finite union of null sets is null, so for Haar-a.e. V the product is nonzero and M is not unitary. (ii)⇒(iii) trivial. (i)⇔(iv): (i)⇒(iv) is the exclusivity Lemma (PFUL.exclusivity L-226). (iv)⇒(i): if s ≠ s' were both fixed points of f∘w, take k from (iv): sk = fk(wk(s)) = fk(wk(s')) = s'k, contradiction; so N(f) ≤ 1 for every f. And Σf N(f) = Σs ∏_k dkdk−1 = ∏_k dkdk = #interventions, so the mean of N is 1 and N ≡ 1. ∎

So: every PF lifts with no party ancilla (equal alphabets), and every map whose ancilla-free loop is unitary for all local unitaries is a PF. Ancillas are not needed for the converse; a single generic draw is a complete test. What the ancillas buy in the copy gadget is a deterministic, explicit witness (column norm = fixed-point count). Side remark: column norms alone cannot do it without ancillas. Σs ∏_k |Vk[sk,wk(s)]|² is multilinear in the unistochastic matrices |Vk|², so it equals 1 on all of them iff N(f) = 1 for all bijective f; the 39,576 three-party binary non-PFs below pass that test, and only the row (orthogonality) conditions detect them.

L.4. Converse for countable alphabets [proved, Lean, with and without ancillas]

Finitely many parties, Ik, Ok countable (finite or ℕ), PF = every f has exactly one fixed point (as in PFUL.Countable). Give each Ok a group structure (Zn or Z). Claim C.1. If w is not a PF, the copy gadget Vk|i,x⟩ = |fk(i)+x, i⟩ on ℓ²(Ik × Ok) → ℓ²(Ok × Ik) (a bijection of basis vectors, hence unitary on ℓ²) gives a closed loop with no unitary (indeed no isometric) realisation. Proof. The loop wiring is a permutation, so the entries M[(s,y),(e,x)] = ∏_k Vk[(sk,yk),(wk(s)+ek,xk)] are finite products, no series. Column (0,0) is the indicator of {(s, w(s)) : f(w(s)) = s}, with N(f) ∈ {0,1,2,…,∞} entries. Any isometry Φ with Φδ_c = M(·,c) needs ‖M(·,(0,0))‖² = 1; but it is N(f) ≠ 1 (for N = ∞ the column is not even in ℓ², so no bounded operator has these matrix entries). ∎ So with ancillas, Theorem 1.2 holds for countable alphabets: (⇐) is PFUL.Countable.induced_unitary_l2 L-002 (Lean), (⇒) is C.1 (now also Lean, see below). Nothing in the finite proof used finiteness except the target statement "M not an isometry", which C.1 replaces by the column-norm obstruction. Example of the N = ∞ case: one party, I = O = ℕ, w = id, f = id. Where it breaks. (a) Continuous alphabets: the gadget is still unitary on L² (shear+swap preserves Lebesgue measure, for measurable f), but basis vectors δ_c are not in L², so "column norm = fixed-point count" has no meaning; one needs a measure-theoretic replacement (cf. F.5). (b) Without ancillas on countable alphabets (superseded by L.4(b) below; original text kept): the Gram identity and "exclusivity ⇒ N(f) ≤ 1" survive, but the averaging step Σf N(f) = #f needs finiteness (this obstacle is now obsolete: the converse goes through without any counting, via the induction existsUnique_of_exclusive L-121; see L.4(b) below), and there is no Haar measure on U(ℓ²) (genericity would have to be redone, e.g. with finite-rank perturbations). For two parties exclusivity forces one of wA, wB to be constant, hence a PF, so a countable counterexample to "exclusive ⇒ PF" would need ≥ 3 parties. [was open; resolved in L.4(b) below]

L.4(b). Converse without ancillas for countable alphabets [proved, Lean; standard axioms only] (Nov 1 2026). PFUL.Countable.unitary_l2_noAncilla_iff_pf L-177 (lean/PFUL/NoAncillaL2.lean): with finitely many parties, countable alphabets with an abelian-group structure on each input alphabet Ik (AddCommGroup (I k), as in Lean; via the bijection this is equivalent to putting it on Ok), a bijection ek : Ok ≃ Ik given as a parameter, decidable equality on ι, Ik, Ok (harmless, as everything is classical), and no ancillas (Xk = Yk = Unit), the closed loop is a unitary of ℓ² for every admissible tuple of local unitaries (square-summable orthonormal rows, unit columns) iff w is a PF. The closed loop Φ (wiring o ↦ shift by w(o) in I) depends on the chosen group law on Ik; it does not depend on e, which is used only to build the witnesses and to show Ok is nonempty. The proof has two pieces, neither of which counts fixed points, so neither needs finiteness or Haar measure:

  • Exclusive ⇒ PF on any alphabets (PFUL.FiniteBox.existsUnique_of_exclusive L-121, lean/PFUL/ExclusiveInduction.lean). Uniqueness is fixed_unique L-125. Existence is by induction on a set T of active parties, the rest frozen (exists_partial_fixed L-122): adding party n, for each value c of n take the configuration s(c) fixed on T; for c ≠ c′ the exclusivity witness k cannot be frozen (both configurations agree there) nor in T (both fixed there, wk agrees), so k = n, hence fn(wn(s(c))) is independent of c, and its common value closes the loop. This also gives a counting-free proof of the finite case.
  • Unitary for all local unitaries ⇒ exclusive (P1, PFUL.Countable.exclusive_of_unitary_l2 L-175). If exclusivity fails at s ≠ s′, at each party choose a local unitary whose row overlap Σi V(sk, wk(s)+i)·conj V(s′_k, wk(s′)+i) is nonzero: where sk = s′_k but wk(s) ≠ wk(s′), the real rotation with entries 3/5, 4/5 on the two points {p, p + wk(s) − wk(s′)} (p = e(sk)), identity elsewhere (its row p is nonnegative and the overlap contains the term (4/5)(3/5) > 0); elsewhere a permutation adjusted by one transposition, giving overlap 1. The row Gram sum of the closed loop factorises into these overlaps (hasSum_pi_prod L-200), so it is nonzero, contradicting orthonormality of the rows of a unitary (rows_of_lie L-176). Continuous alphabets remain uncovered. Independent read-only check (2026-11-01): the Lean definitions and quantifiers match the paper's notions.

That set is an illustration. It is not a separate Lean declaration. Countability does not follow from closedness, and closedness does not follow from countability: the finite-support set of zfcF is countable and not closed.
    • Finite global image [proved, Lean; lean/PFUL/FiniteGlobalRange.lean]: for any party set, an exclusive self-map of Bool^ι with finite image of the whole output vector has a fixed point (exists_fixed_of_finite_global_range L-304). No continuity, Baire class, or countability of the party set is used. More strongly, an exclusive w : Bool^ι → ∏ Ak with finite global image is a process function for every family of local Boolean responses (isProcessFunction_of_exclusive_finite_global_range L-305). The input alphabets Ak are arbitrary. Each Boolean coordinate already has a two-point image; that per-coordinate fact does not settle infinitely many parties. The theorem is about one finite palette of whole output vectors.
    • Output range in one finite-difference class [proved, Lean; lean/PFUL/GeneralRange.lean]: if every point of the closure of the range of an exclusive F differs finitely from a fixed c, then F has a fixed point (exists_fixed_of_rangeClosure_finite_diff L-306). No exceptional set is assumed. A uniform bound of K on the number of output coordinates that differ from c is a corollary (exists_fixed_of_bounded_output_diff L-307), as is a closed range contained in one finite-difference class with no uniform bound (exists_fixed_of_closed_range_finite_diff L-308). This is a hypothesis on outputs. It is distinct from the earlier bounds on exceptional inputs (L-272, L-290). It does not say that a Baire-one range satisfies the hypothesis.
    • Finite-prefix normalizers [proved, Lean; lean/PFUL/PrefixNormalizers.lean]: for exclusive F, Pn(b) is the unique history with tail b from n onward that is consistent on the first n coordinates (prefix_solution_unique L-309). They satisfy Pm ∘ Pn = Pmax(m,n) (prefixNormalize_comp L-310). If F is Baire class 1, so is each Pn (baireOne_prefixNormalize L-311): the proof reads the whole finite truth table of continuous approximants and does not claim those approximants are exclusive. If Pn converges pointwise to L, then L is invariant under finite coordinate changes of its input (normalizer_limit_tail_invariant L-312). A Boolean Baire-one map with that invariance is constant (eq_of_baireOne_tail_invariant_bool L-313), so a Baire-one limit L is constant (normalizer_baireOne_limit_constant L-314). Baire class 1 of F does not prove that the limit exists, and it does not prove that a pointwise limit stays Baire class 1. A cluster point of solved prefixes is a fixed point if every Pm is continuous there in the ambient Cantor space (fixed_of_normalizer_cluster_continuity L-315). Continuity of F or Pm only on the cluster set does not supply that hypothesis: prefix solutions may approach the set from outside it. For zfcF and the zero boundary the cluster set is the singleton of all ones, so every restriction to it is continuous, and there is still no fixed point. That diagnoses the gap. It is not a Baire-one counterexample. If Pn(p) → p and F(p) differs from p only finitely often, then p is fixed (fixed_of_normalizer_self_limit_finite_defect L-316).
    • Exclusivity need not pass to the pointwise limit [proved, Lean; lean/PFUL/ExclusiveLimitFailure.lean]: the continuous maps YN, equal to true from coordinate N on and Yablo-like below N, are each globally exclusive (finiteYablo_exclusive L-317). They converge pointwise to the Yablo map, which is Baire class 1 and fixed-point-free and not exclusive (continuous_exclusive_limit_can_fail_exclusive L-318). This is not a counterexample to "exclusive and Baire class 1 ⇒ fixed point": the limit fails exclusivity. Exclusivity does survive for pairs that differ in only finitely many coordinates (finite_pair_exclusive_of_pointwise_limit L-319, and for Yablo yablo_finite_pair_exclusive L-320). The witnesses that escape are those of pairs differing infinitely often.
    • A rejected shortcut [proved, Lean; lean/PFUL/GeneralProbe.lean]: the finite exclusive map (a, b) ↦ (not b, true) has a maximal postfixed point that is not fixed (maximal_postfixed_need_not_be_fixed L-321, checked by decide). Maximality of x ≤ F(x) does not become equality from exclusivity alone. This refutes that proposed proof. It does not refute every possible semicontinuity theorem.
    • Open [conjectural]: whether a Baire-class-1 exclusive map can be fixed-point-free, including one that is constant off an arbitrary countable set; and whether any Borel triangular exclusive map can. Countable closed exceptional sets, countable G-delta exceptional sets, finite global output image, and output ranges trapped in one finite-difference class are settled. No exclusive Baire-one counterexample is known. These open questions sit among the other open questions of the note (Section 10).
    • Literature: no treatment of infinitely many parties was found (paper/notes/2026-11-03-zfc-infinite-parties.md).
