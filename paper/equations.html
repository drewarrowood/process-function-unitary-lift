Every process function lifts to a unitary process

The displays below are the equations of the proof sketch, not a second notation.

Fixed point

An intervention is a tuple of local functions. The fixed point is an output string.

o = f(w(o)).

The map w is a process function when every f has exactly one solution o.

Lugano

w(a, b, c) = (¬b ∧ c,   ¬c ∧ a,   ¬a ∧ b).

As in the paper. On bits the image has four elements out of eight.

Extension

As in the paper. The sum is the group law. On bits it is exclusive or, and plus and minus agree.

U |o, e⟩ = |w(o) + e,   o⟩.

U−1 |i, s⟩ = |s,   i − w(s)⟩.

Both compositions are the identity on bits. That is the kernel check. The 2019 paper has the general classical case.

Lemma

If w is a process function and s ≠ s', some party k has sk ≠ s'k and wk(s) = wk(s').

The local function used in the proof is the one in the paper:

fk(wk(s)) = sk,   fk(wk(s')) = s'k,

and arbitrary off those symbols. Then f(w(s)) = s and f(w(s')) = s'.

Contraction

The amplitude in the paper, with the same shift:

Ms,e = ∏k ⟨sk| Vk |wk(s) + ek⟩.

δk = wk(s') − wk(s).

(MM†)s,s' = ∏k ∑i ⟨sk| Vk |i⟩ ⟨i + δk| Vk† |s'k⟩.

MM† = I.

On the diagonal every δk vanishes and each factor is a row norm. Off the diagonal the lemma supplies a party with δk = 0 and sk ≠ s'k, so that factor is zero. This identification is written, not kernel-checked. Fixing the source at the identity recovers w.

Channel, the case that embeds

iB = w(oA),   iA independent of oB.

Or the reverse. This is the ordered case in the paper. Lugano has no such wiring.
