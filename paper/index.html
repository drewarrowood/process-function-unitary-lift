Unique completion as a quantization condition

Process functions, a unitary lift, and what is not a metric.

Lean, the kernel-checked half: lean/Full.lean. The disagreement lemma and the bit bijection are there. lean/Cancel.lean is the cancellation on bits. lean/Gaps.lean records what was not checked. Directory: lean/.

What is shown

Shown, Lean 4.34.1: if a process function sends two distinct output strings, some party disagrees in the output and agrees in the function value. On bits the source-and-sink map is a bijection, both ways. Lugano has one fixed point for every binary intervention. The identity loop and the three-cycle do not.

Written, not kernel-checked: the gram matrix of the source-to-sink operator is the identity against complex local unitaries. Instruments follow by Stinespring. Not claimed: a metric for Lugano.

The equations

o = f(w(o)).

No solution is the grandfather case. Two solutions is the bootstrap. The map is a process function when every intervention has exactly one solution. The clause can be failed. The identity loop fails it. The swap fails it. Faye's Stanford entry, revised 28 October 2025, still treats a stipulation that only consistent loops occur as not an answer. This clause can be failed from inside the theory.

w(a, b, c) = (not b and c, not c and a, not a and b).

Lugano. Each input depends on the other two outputs. The image has four elements out of eight, so the map is two-to-one.

(o, e) maps to (w(o) XOR e, o).

(i, s) maps to (s, i XOR w(s)).

Both compositions are the identity on bits. That is the check in Full.lean. A finite bijection is a permutation unitary. That is representation, not yet a quantum process.

The contraction

If s differs from s', some party disagrees in the output and agrees in the function value. Otherwise one local function fixes both strings. The shift is delta_k = w_k(s') XOR w_k(s). The gram entry factors. On the diagonal every shift vanishes. Off the diagonal the witness party contributes the inner product of two distinct rows, which is zero. So M M-dagger = I. This identification is written. It is not in the Lean file.

Embeddability

Channels embed as free propagation. Lugano violates a causal inequality, so no mixture of definite orders embeds it if the settings are free. The billiard has the wrong multiplicity. A source and a sink are extra regions, not a throat.
