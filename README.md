# Process-function unitary lift

Draft note, Foundations of Physics style, arguing that every classical deterministic process function lifts to a valid unitary quantum process.

The dilation is the source-and-sink permutation unitary of Baumeler, Costa, Ralph, Wolf and Zych (Theorem 2, 2019). The process-function clause is what kills the shift term under arbitrary local unitaries.

This is a claimed argument addressing the conjecture stated by Daher Ahmed and Kunjwal (arXiv:2610.00579, 30 September 2026). It is not kernel-checked. The combinatorial lemma is the step an attacker has to break.

- `paper/lift.md` — the note
- `code/verify_lift.py` — numerical certificate for the Lugano function and a contrast with non-process functions
